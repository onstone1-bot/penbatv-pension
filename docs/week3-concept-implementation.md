# 3주차 개발 진행안

일자: 2026-08-15

## 목표

2주차까지 만든 예약/결제 기능을 다시 컨셉 관점에서 정비했다. 3주차는 캠핑천국 유튜브 유입 고객이 헷갈리지 않고 예약까지 이동하도록 고객 화면의 설득 흐름을 보강하고, 펜션 운영자가 네이버예약처럼 예약요청과 차단일을 확인할 수 있는 운영 콘솔을 구체화한다.

## 고객 화면 개선

경로:

```text
/stays/baebang-alps?utm_source=youtube&utm_medium=video&utm_campaign=campheaven_room_01&room=A
```

구현:

- 유튜브 시청 후 예약으로 이어지는 3단계 전환 흐름 추가
- 객실 상세 화면에 영상 체크포인트와 예약 확정 기준 표시
- 달력식 날짜 선택과 예약 가능 여부 확인 유지
- 예약자 정보 단계에서 예약 방식을 선택하도록 개선
- 예약요청: 운영자가 확인 후 결제 링크를 발송하는 MVP형 흐름
- 바로결제: 예약 가능 기간을 15분간 선점하고 결제 준비 API로 이어지는 자동 확정형 흐름

## 운영자 화면 개선

경로:

```text
/host/rooms
```

구현:

- 예약 운영 요약 지표 추가
- 예약 요청함 추가
- 예약 상태를 확인필요, 결제대기, 확정으로 구분
- 객실별 기본 요금, 주말 요금, 이미지 수, 요금 규칙 수 표시 유지
- 객실별 요금 수정, 차단일 추가, 화면 숨기기 액션 배치
- 예약 차단일 목록 추가
- 유튜브 유입 예약 운영 체크리스트 추가

## 3주차 의사결정

- 1차 MVP의 기본 예약 방식은 `예약요청`으로 둔다.
- 성수기나 재고가 명확한 객실은 `바로결제`를 선택할 수 있게 한다.
- 네이버예약 벤치마킹 범위는 결제창 복제보다 운영 상태 관리 UX에 둔다.
- 캠핑친구형 탐색 UI는 홈과 목록에 유지하되, 유튜브 유입 고객에게는 상세 랜딩 중심으로 전환한다.
