# 펜바TV 3주차 15-21일차 진행 정리

## 15일차: 날짜별 객실 예약 가능 여부

- 고객 숙소 화면의 달력에서 선택 객실 기준으로 `/api/availability/calendar`를 호출합니다.
- `bookings`, `booking_holds`, `room_blocks`를 함께 확인해 예약완료, 결제중 선점, 운영자 차단일을 선택 불가로 표시합니다.

## 16일차: 객실 선택 후 사진/영상 확인

- 일정과 인원을 먼저 고른 뒤 객실을 선택합니다.
- 선택 객실의 내부/외부 사진과 연결된 유튜브 영상을 같은 단계에서 확인하고 결제로 넘어갑니다.

## 17일차: 인원/옵션 선택

- 성인/아동 인원 선택을 객실 최대 인원 기준으로 제한합니다.
- 바비큐 옵션 선택 시 바비큐장 이용 시간도 함께 선택합니다.

## 18일차: 서버 기준 견적 계산

- 화면 선택값을 `/api/quote`로 보내고 서버가 객실 요금, 주말/성수기, 추가 인원, 옵션, 유튜브 할인 금액을 다시 계산합니다.
- 고객 브라우저에서 금액을 바꿔도 `/api/payments/prepare`가 서버 견적을 다시 계산한 금액으로 결제 주문을 생성합니다.

## 19일차: 결제 준비 API

- `/api/booking-holds`로 선택 객실과 날짜를 15분간 선점합니다.
- `/api/payments/prepare`가 결제 주문을 저장하고 카드, 네이버페이, 토스페이, 실시간 계좌이체, 가상계좌, 수동계좌이체 모드를 준비합니다.

## 20일차: 결제 성공 후 예약 확정

- `/api/payments/confirm`이 결제 금액과 서버 저장 주문 금액을 비교합니다.
- 금액이 맞으면 `bookings`, `payments`, `booking_option_items`를 저장하고 예약 확정 또는 입금대기 상태로 전환합니다.

## 21일차: 내예약에서 예약 확인

- 결제 확정 응답에 `bookingId`, `bookingNo`를 포함했습니다.
- 완료 화면에서 `/my`로 이동하면 로그인 고객 ID 또는 휴대폰 번호 기준으로 DB 예약을 조회합니다.

## 현재 시연 흐름

1. 고객이 유튜브 설명란 링크로 `/stays/baebang-alps`에 진입합니다.
2. 달력에서 예약 가능한 날짜를 선택합니다.
3. 성인/아동 인원과 바비큐 옵션을 선택합니다.
4. 객실 사진과 유튜브 영상을 확인합니다.
5. 결제 방식 선택 후 결제를 진행합니다.
6. 결제 성공 또는 입금대기 예약이 저장되고 내예약에서 확인합니다.

## 아직 실제 운영 전 필요한 외부 설정

- Supabase 운영 DB 마이그레이션 반영 여부 확인
- 토스페이먼츠 실운영 키 전환
- 네이버페이 실제 가맹/PG 설정
- 카카오/네이버 로그인 Redirect URL 운영 도메인 등록
- 알림톡 발신 사업자/템플릿 승인
